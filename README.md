# BACT7501 Assessment 2 – Purchase Requisition System

## Project Overview
This project is a Purchase Requisition System developed using Python for my BACT7501 Programming I Assessment 2.

The system allows staff to enter purchase requests, calculate the total cost, and check the approval status. It also allows a manager to review pending requests and displays requisition statistics.

## Main Features
- Enter staff information, including date, staff ID, and staff name.
- Add purchase items and calculate their total cost.
- Automatically approve requisitions below $500.
- Send requisitions of $500 or more for manager review.
- Allow the manager to approve or reject pending requisitions.
- Display requisition details and approval reference numbers.
- Show initial and final requisition statistics.
- Check user inputs to prevent empty entries.

## Programming Concepts Used
- Python classes and objects
- Methods
- Variables and lists
- Loops
- If-else conditions
- User input and validation
